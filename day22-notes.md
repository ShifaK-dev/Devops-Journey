# Day 22 - LinkedIn & GitHub Optimization

## Objective

Build a professional online presence using LinkedIn and GitHub.

---

# Why LinkedIn?

LinkedIn is the most important professional networking platform.

Recruiters use LinkedIn to:

- Find candidates
- Verify resumes
- View projects
- Check technical skills

# GitHub Best Practices

Use professional commit messages.

Examples:

Good:

- Add Docker deployment notes
- Configure GitHub Actions workflow
- Deploy application on AWS EC2

Avoid:

- notes added
- update
- done
