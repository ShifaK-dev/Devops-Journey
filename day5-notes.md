# Day 5 Notes

## Git vs GitHub

### Git
- Version control system used locally on computer
- Tracks file changes and project history

### GitHub
- Cloud platform used to store repositories online
- Enables backup, sharing, and collaboration

## Local Repository vs Remote Repository

### Local Repository
- Repository stored on personal computer

### Remote Repository
- Repository stored online on GitHub

## GitHub Workflow

Learn
→ Modify files
→ git add
→ git commit
→ git push

## Important Git Commands

### git remote add origin
- Connects local repository with GitHub repository

### git branch -M main
- Renames current branch to main

### git push
- Uploads local commits to GitHub

### git clone
- Downloads complete repository from GitHub

### git pull
- Downloads latest updates from GitHub to local repository

## Collaboration Workflow

Developer A
→ Push changes to GitHub

Developer B
→ Pull latest updates from GitHub

## README.md

### README.md
- Main documentation/introduction file of project
- Usually contains:
  - Project purpose
  - Features
  - Instructions
  - Notes

## .gitignore

### .gitignore
- Tells Git which files/folders to ignore

Examples:
- node_modules/
- .env

Used to avoid:
- secret files
- temporary files
- unnecessary uploads

## Branches

### Branch
- Separate version/line of development
- Used to test features safely without affecting main project

## Merge

### Merge
- Combines changes from one branch into another

## Important Concepts Learned

- Difference between Git and GitHub
- Local vs remote repositories
- GitHub collaboration workflow
- Push vs pull vs clone
- Importance of documentation
- Purpose of branches and merges
