# Day 19 - Monitoring Concepts (Prometheus & Grafana)

## Objective

Learn the fundamentals of monitoring, logging, downtime, alerts, and understand the roles of Prometheus and Grafana in a DevOps environment.

---

# Why Monitoring?

Monitoring helps engineers continuously observe the health and performance of systems, servers, applications, and services.

Without monitoring:

Website Down
↓
Users Complain
↓
Nobody Knows Why

With monitoring:

Problem Occurs
↓
Alert Generated
↓
Engineer Notified
↓
Problem Resolved

---

# What is Monitoring?

Monitoring is the process of continuously tracking the health and performance of systems.

Examples:

- CPU Usage
- Memory Usage
- Disk Usage
- Network Usage
- Application Availability

---

# Logging

## What are Logs?

Logs are records of events generated by applications and systems.

Think of logs as:

System Diary 📖

Examples:

```text
2026-05-31 10:00 User Login Success
2026-05-31 10:05 User Logout
2026-05-31 10:10 Server Restart
```

---

## Linux Logs

View system logs:

```bash
sudo journalctl
```

Purpose:

Display system and service logs.

---

# Monitoring vs Logging

## Logging

Answers:

```text
What happened?
```

Examples:

- User logged in
- Database crashed
- Nginx restarted

---

## Monitoring

Answers:

```text
How healthy is the system?
```

Examples:

- CPU = 40%
- RAM = 65%
- Disk = 75%

---

# Downtime

## What is Downtime?

The period during which a service is unavailable.

Example:

```text
10:00 AM Website Working
10:05 AM Website Down
10:20 AM Website Fixed
```

Downtime:

```text
15 Minutes
```

---

# Uptime

Uptime is the amount of time a service remains available.

Example:

```text
99.9% Uptime
```

Means the service is available almost all the time.

---

# Alerts

Monitoring tools can automatically notify engineers when problems occur.

Examples:

```text
CPU > 90%
RAM > 90%
Disk Space < 10%
Website Down
```

Alert Flow:

```text
Problem Detected
↓
Alert Generated
↓
Email / Slack / SMS Sent
↓
Engineer Responds
```

---

# Prometheus

## What is Prometheus?

Prometheus is an open-source monitoring and metrics collection tool.

Purpose:

- Collect Metrics
- Store Metrics
- Monitor Systems

Examples of Metrics:

- CPU Usage
- Memory Usage
- Disk Usage
- Network Traffic

---

## Prometheus Flow

```text
Server
↓
Metrics
↓
Prometheus
↓
Stores Metrics
```

---

## Example Metrics

```text
CPU = 20%
RAM = 45%
Disk = 60%
```

Prometheus continuously collects these values.

---

# Grafana

## What is Grafana?

Grafana is an open-source visualization and dashboard platform.

Purpose:

- Display Metrics
- Create Dashboards
- Visualize Trends

---

## Grafana Flow

```text
Prometheus
↓
Metrics
↓
Grafana
↓
Dashboards & Graphs
```

---

# Prometheus vs Grafana

| Tool | Purpose |
|--------|----------|
| Prometheus | Collect and store metrics |
| Grafana | Visualize metrics and create dashboards |
