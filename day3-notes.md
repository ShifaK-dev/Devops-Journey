# Day 3 Notes

## Process Management

### ps
- Shows running processes in current terminal session

### ps -e
- Shows all running system processes

### top
- Live system monitoring tool
- Shows CPU, memory, and active processes

### kill
- Stops a running process using PID

### sleep
- Creates a waiting/running process for practice

## Permissions

### ls -l
- Shows detailed file permissions

### chmod +x
- Adds execute permission to a file

## Permission Types
- r = read
- w = write
- x = execute

## Shell Script Concepts
- Commands inside scripts are executed line by line
- Linux is sensitive to spacing and syntax

## grep
- Searches text inside files

## find
- Searches files and directories

## history
- Displays previously used terminal commands

## Important Concepts Learned
- Processes vs commands
- Data files vs executable scripts
- Recursive searching
- Hidden files in Linux
- Linux permissions and security
